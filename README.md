# 🏔️ GeoTrails - Georgian Hiking & Adventure Guide

GeoTrails is a high-performance web application designed for discovering hiking trails and outdoor adventures across Georgia. The project emphasizes a premium UI/UX experience and a scalable frontend architecture.

---

## 🚀 Overview

The primary goal of this project was to build a robust, modular frontend using **Angular** that can handle complex data structures. Although currently utilizing a Mock API service, the entire data layer is built to be seamlessly swapped with a live REST API.

## 🛠️ Technical Stack & Patterns

* **Framework:** Angular (Latest Version)
* **State Management:** Reactive streams with **RxJS**
* **Styling:** SCSS (Modular & Responsive)
* **Architecture:** * **Smart/Dumb Component Pattern:** Decoupling business logic from presentation.
    * **Mock Service Layer:** Implementing `Observable`-based services to simulate real-world asynchronous data fetching.
    * **Strategic Routing:** Dynamic routing for trail categories and detailed exploration pages.

## ✨ Key Features

* **Interactive Trail Discovery:** Browse through curated hiking spots with dynamic filtering.
* **Mock API Integration:** A fully functional data layer that mimics backend behavior using RxJS operators.
* **Performance Optimized:** Clean component lifecycle management to ensure a smooth user experience.
* **Responsive UI:** Crafted with a mobile-first approach for hikers on the go.
